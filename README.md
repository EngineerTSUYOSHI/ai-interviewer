# 🎙️ AI Interviewer (マルチ面接官AIシミュレーター)

志望企業の情報・募集要項・あなた自身の経歴を登録し、**視点や性格の異なる複数のAI面接官（テックリード、人事、役員など）とリアルタイムに対話する面接対策シミュレーター**です。

音声（ブラウザ標準 Web Speech API）でのリアルな対話に対応し、面接終了後には**「面接官同士が裏で自律的に行う合否判定ミーティング」**の議事録や、各面接官の本音メモ、レーダーチャート評価、具体的な満点模範解答を出力します。

---

## ✨ 主な特徴

1. **🎭 複数面接官システム（Multi-Interviewer System）**
   - 役割・性格・評価基準が異なる面接官を1人〜複数人設定可能。
   - 例: 「技術の深掘りや設計思想を厳しく突くテックリード」「カルチャーマッチや行動特性を重視する人事責任者」「事業成長や経営視点で質問する役員」。
   - 面接官同士が順番に質問したり、前の回答に対して別角度から深掘りしたりと、自然なパネル面接を再現。

2. **💭 面接官の「心の声メモ」（Inner Thoughts）**
   - 候補者の発言中、各面接官が心の中で感じた「好印象な点」「違和感・懸念点」「次に確認したいポイント」をリアルタイムに記録。

3. **🗣️ 無料・低遅延な音声対話（Web Speech API）**
   - ブラウザ標準の Speech-to-Text（音声認識）でマイクからスピーチ入力。
   - 面接官ごとの声色・ピッチ・速度を変えた Text-to-Speech（音声合成）により、外部有料音声APIを使わずに完全無料でリアルな音声対話を実現。

4. **👥 裏の合否判定ミーティング（Autonomous Post-Interview Meeting）**
   - 面接終了後、面接官エージェント同士が自律的にディスカッションを実施。
   - 「技術力は高いがカルチャー面で懸念がある」「いや、あの受け答えなら伸び代がある」など、リアルな選考会議の議事録を可視化。

5. **📊 多面的フィードバック ＆ 満点模範回答**
   - 評価項目（技術的深さ、論理的思考力、カルチャーフィット、熱意・主体性など）のレーダーチャート。
   - 曖昧だった回答に対して「こう答えれば合格水準だった」という具体的な改善解答を提示。

## 🏗️ システムアーキテクチャ

```text
[ ブラウザ画面 (フロントエンド) ]
  Modern Web UI (Dark Mode & Glassmorphism)
  - 企業情報・求人票・候補者経歴の設定フォーム
  - 面接官アバターカード（状態・発話中インジケータ）
  - 音声入力 (Web Speech API / Speech-to-Text)
  - 音声読み上げ (Web Speech API / Text-to-Speech 声色分け)
  - リアルタイム心の声メモ ＆ 対話ログ
      ▲
      │ WebSocket (リアルタイム双方向通信)
      ▼
[ サーバー側 (バックエンド / Python) ]
  FastAPI (Uvicorn)
  ├─ Interview Coordinator (進行管理)
  │    ├─ 質問ターンの制御・割り振り
  │    ├─ 面接終了判定
  │    └─ ★裏の合否判定ミーティングの自律討議オーケストレーション
  └─ Interviewer Agents (面接官AIエージェント群)
       ├─ Perception (候補者の回答、企業理念、求人要件)
       ├─ Inner Thoughts (リアルタイムの本音・評価メモの蓄積)
       └─ LLM Core (Google Gemini 2.5 Flash / Structured Outputs)
```

---

## 🛠️ 技術スタック

* **Backend:**
  * Python 3.11+
  * FastAPI / Uvicorn（非同期Web API ＆ WebSocketサーバー）
  * `google-genai` SDK（Gemini 2.5 Flash による低遅延・高精度な対話生成）
  * Pydantic v2（構造化データバリデーション）
  * uv（高速パッケージ管理ツール）
* **Frontend:**
  * HTML5 / CSS3 (Vanilla CSS, CSS Custom Properties, Glassmorphism, Micro-animations)
  * JavaScript (ESModules)
  * Web Speech API (SpeechRecognition & SpeechSynthesis - 完全無料・追加課金なし)
  * WebSocket クライアント
